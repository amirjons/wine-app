# Wine Quality: рекомендатель хороших вин

Streamlit-приложение: оценка одного вина, метрики модели при выбранном пороге, пакетное предсказание по CSV и коэффициенты логистической регрессии. Модель в приложении не обучается: используется пайплайн `StandardScaler + LogisticRegression` из `model.joblib`.

## Запуск

Версия Python: **3.12** (проверено на 3.12.3).

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Файлы

- `app.py` - приложение;
- `model.joblib` - обученный пайплайн (scikit-learn 1.9.1, версии должны совпадать с `requirements.txt`);
- `config.json` - порог по умолчанию (`threshold`);
- `test.csv` - тестовая выборка с колонкой `target`;
- `requirements.txt` - версии библиотек.

## Кэширование

- `st.cache_resource` используется для модели: возвращается один и тот же объект на весь сервер, без копирования; так и нужно хранить тяжёлые объекты вроде моделей.
- `st.cache_data` используется для таблиц и массивов (`test.csv`, вероятности на тесте, кривые): при каждом вызове возвращается копия, поэтому данные нельзя случайно изменить между сессиями.
- Без декоратора `joblib.load` выполнялся бы при каждом действии пользователя (например, при каждом движении слайдера): модель каждый раз читалась бы с диска, а приложение работало бы медленнее. Вероятности на тесте от порога не зависят, поэтому считаются один раз; при движении слайдера пересчитывается только сравнение с порогом.
